# 测试点提取技能 (Testpoint Extractor)

## 1. 技能定位

本技能专注于**阶段3：测试点提取** 和**阶段4：XMind生成**工作，负责：

1. 按章节读取需求 JSON 文档及关联图片
2. **遍历章节JSON中每一个需求，将每个需求描述和图片一起给大模型**提取这个需求的测试点
3. 每个需求的测试点提取完成之后，都要更新任务清单，一个一个需求点进行提取，可以并发调用子agent来完成任务
3. 生成 XMind 格式的测试计划文档

**前置依赖**：requirement-splitter 技能已成功执行并输出 JSON 需求文档和图片文件

---

## 2. 输入输出规范

### 2.1 输入

| 参数                | 类型 | 说明                                            |
| ------------------- | ---- | ----------------------------------------------- |
| `requirements_json` | path | 需求 JSON 文件路径（requirement-splitter 输出） |
| `output_dir`        | path | 输出目录路径                                    |

### 2.2 期望的输入目录结构

```
{output_dir}/
├── {项目名称}/
│   ├── 03_requirements/
│   │   ├── 01_第3章_xxx/
│   │   │   ├── requirements.json
│   │   │   ├── requirements_detail.json  # 详细需求（含完整原文）
│   │   │   └── images/                  # 该章节关联的图片 ← 关键！
│   │   └── ...
│   └── 04_testpoints/
│       └── ...
```

> **重要**：requirement-splitter 必须在输出需求 JSON 的同时，复制关联图片到对应章节的 `images/` 目录下。

## 3. 核心处理逻辑

### 3.1 图片+文本联合输入

每个需求的测试点提取，需要将以下信息**一起**给到测试点提取的子Agent：

```
┌─────────────────────────────────────────────┐
│  需求信息 (给大模型)                         │
├─────────────────────────────────────────────┤
│  需求ID：REQ-CH3-001                        │
│  需求名称：用户订票功能                       │
│                                             │
│  【需求描述 - 完整原文】                      │
│  用户可以通过B2C前台完成机票订购操作，         │
│  支持选择出发地、目的地、航班和舱位...        │
│  （完整保留原文所有内容）                     │
│                                             │
│  【关联图片】                                │
│  ┌─────────────────┐                        │
│  │   [图片1]       │  ← 流程图/界面截图     │
│  │   3a1d746c.jpg  │                        │
│  └─────────────────┘                        │
│  图片描述：展示了用户订票的完整流程...        │
│                                             │
│  【验收标准】                                │
│  1. 用户可选择出发地和目的地                 │
│  2. 系统展示可用航班列表                     │
│  3. ...                                     │

```

例：TP-CH3-001-001  表示第3章第1个需求的第1个测试点
```

## 5. 测试点提取规则

### 5.1 测试点类型

| 类型     | 代码 | 说明                         |
| -------- | ---- | ---------------------------- |
| 功能测试 | FT   | 验证功能是否符合需求         |
| 边界测试 | BT   | 测试边界值条件               |
| 异常测试 | ET   | 测试异常情况和错误处理       |
| 性能测试 | PT   | 测试性能指标                 |
| UI测试   | UIT  | 测试界面交互（**基于图片**） |
| 安全测试 | ST   | 测试安全相关功能             |

### 5.2 优先级定义

| 优先级 | 说明               | 适用场景                 |
| ------ | ------------------ | ------------------------ |
| P0     | 核心功能、基本流程 | 必须通过，否则功能不可用 |
| P1     | 重要功能、常用场景 | 应该通过，影响主要流程   |
| P2     | 一般功能、特殊场景 | 可以尝试，不阻塞上线     |
| P3     | 边缘功能、低频场景 | 可选                     |

### 5.3 图片关联测试点提取

**重要**：当需求中包含关联图片时，测试点提取需额外考虑：

| 图片类型   | 提取的测试点                                   |
| ---------- | ---------------------------------------------- |
| 流程图     | **流程测试**：验证功能流程与图中一致           |
| 界面截图   | **UI测试**：验证界面元素、布局、交互与截图一致 |
| 状态机图   | **状态转换测试**：验证状态转换符合图示         |
| 架构图     | **配置测试**：验证配置与架构一致               |
| 数据示例图 | **数据验证测试**：验证数据展示与图示一致       |

**图片测试点提取示例**：

```json
{
  "testpoint_id": "TP-CH3-001-010",
  "testpoint_name": "验证订票流程与流程图一致",
  "test_type": "UI测试 (UIT)",
  "priority": "P1",
  "preconditions": ["已登录B2C系统"],
  "test_steps": [
    "1. 参考 images/3a1d746c.jpg 流程图",
    "2. 按流程图步骤执行：选择出发地→选择目的地→选择航班→填写信息→支付",
    "3. 验证每个步骤与流程图一致"
  ],
  "expected_results": [
    "流程图中的5个步骤均能正常完成",
    "无流程图之外的额外步骤要求"
  ],
  "related_images": [
    "images/3a1d746c.jpg"
  ],
  "notes": "此测试点根据关联的流程图（images/3a1d746c.jpg）提取，确保实际流程与设计流程一致"
}
```

## 9. 执行流程

```
1. 解析输入参数
   ├── 验证 requirements_json 是否存在
   ├── 验证 output_dir 是否有效
   └── 验证 images/ 目录是否存在

2. 读取需求文档
   ├── 解析 requirements.json
   ├── 解析 requirements_detail.json（如有）
   └── 构建需求结构树

3. 图片加载
   └── 对每个需求：
       ├── 读取 related_images 中的图片文件
       └── 将图片内容加载到内存

4. 遍历需求并提取测试点
   └── 对每个需求执行：
       ├── 组装"需求描述+图片"联合输入
       ├── 调用大模型提取测试点
       ├── 解析大模型返回的JSON
       ├── 校验测试点完整性
       └── 保存测试点 JSON

5. XMind 生成
   ├── 整理测试点层级结构
   ├── 生成 XMind 8 格式文件
   └── 保存到 05_xmind/ 目录

6. 生成汇总
   ├── 生成各章节 testpoints.json
   ├── 生成全局汇总 testpoints_summary.json
   ├── 生成 README.md（索引）
   ├── 更新任务清单
   └── 输出执行报告
```

## 10. 错误处理

| 错误情况       | 处理方式                                    |
| -------------- | ------------------------------------------- |
| 需求JSON不存在 | 报错退出，提示先执行 requirement-splitter   |
| 图片文件缺失   | 继续处理，但测试点 notes 中标注"图片缺失"   |
| JSON格式异常   | 跳过异常需求，记录日志，继续处理其他需求    |
| 验收标准为空   | 生成至少1个通用功能测试点                   |
| 大模型调用失败 | 重试3次，仍失败则使用规则引擎生成基础测试点 |

## 12. 三个 Skill 的协作约定

```
┌─────────────────────────────────────────────────────────────────────┐
│                        Skill 协作流程                                 │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│  1. requirement-parser (解析)                                       │
│     文档 PDF/md → 提取文本/图片/表格                                 │
│                                                                     │
│  2. requirement-splitter (拆分)                        ◄──┐        │
│     提取内容 → 需求拆分 → JSON需求文档                         │        │
│     输出：                                                         │  图片+JSON        │
│     - 03_requirements/                                           │  联合输入         │
│     │   ├── xx_chapter/                                          │                   │
│     │   │   ├── requirements.json                                │                   │
│     │   │   ├── requirements_detail.json                          │                   │
│     │   │   └── images/  ← 关联图片复制到此目录    ──────────────┘                   │
│     │   └── ...                                                   │
│     └── requirements_summary.json                                   │
│                                                                     │
│  3. testpoint-extractor (测试点+XMind)                  ───┐       │
│     读取：                                                         │  读取图片         │
│     - requirements_summary.json                                  │  + 需求JSON       │
│     - 03_requirements/*/images/                    ◄─────────────┘                   │
│     - 03_requirements/*/requirements_detail.json                                │
│     ↓                                                                      │
│     生成：                                                                 │
│     - 04_testpoints/                                                    │
│     - 05_xmind/                                                         │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```

### 协作约定

| Skill                | 输出物                 | 后续 Skill 使用              |
| -------------------- | ---------------------- | ---------------------------- |
| requirement-parser   | 原始图片               | 被 requirement-splitter 复制 |
| requirement-splitter | `images/` 目录下的图片 | 被 testpoint-extractor 读取  |
| requirement-splitter | `requirements.json`    | 被 testpoint-extractor 读取  |
| testpoint-extractor  | `testpoints.json`      | 最终输出                     |
| testpoint-extractor  | `.xmind` 文件          | 最终输出                     |
